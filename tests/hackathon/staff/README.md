# تحویل آیدا: بررسی و ممیزی شهرآگاه

`mountStaff(root, api, role)` برای نقش‌های `operator` و `manager` آماده است. پوسته پس از تغییر نقش تابع پاک‌سازی mount قبلی را صدا بزند و نقش تازه را mount کند. فایل‌های تحویل فقط `staff.mjs` و `staff.css` در مسیر بازی‌اند؛ پیش‌نمایش و API بدل زیر `tests` قرار دارند و به صفحهٔ اصلی وارد نمی‌شوند.

پنل براساس شناسه‌های مشترک به پرونده، مشاهده، تصمیم و ممیزی وصل می‌شود. fixture نمونه شکل داده‌های نمایشی را نشان می‌دهد: `cases` عنوان، شماره و خلاصه؛ `entries` متن، زمان، مکان و اثر؛ و `reviews` و `audits` تصمیم، علت و شناسهٔ مسئول. پنل نتیجهٔ تطبیق را از `audits[].matched` و پاداش ثبت‌شده را از `ledger[]` می‌خواند. برای نسبت دادن XP به همان اقدام، هر رویداد XP باید `profileId`، `xp`، `caseId` و ترجیحاً `reviewId` را داشته باشد. برای نتیجهٔ دقیق ممیزی پس از رسیدن به سقف، `matched` را حتی وقتی XP پرداخت نمی‌شود ارسال کنید. کلید نمونه، پرداخت و تشخیص یکتایی در API هستند.

| مشاهده | تصمیم اپراتور | دلیل |
| --- | --- | --- |
| پیام کلی و تکراری | برگشت برای اصلاح | جزئیات تازه ندارد |
| مشاهدهٔ مستقیم با زمان، محل و اثر دسترسی | تأیید پیوست | شاهد تازه و قابل اقدام |
| شنیده بدون مشاهدهٔ مستقیم | برگشت برای اصلاح | قابل راستی‌آزمایی نیست |

آزمون محلی: `node --test tests/hackathon/staff/acceptance.test.mjs`؛ برای پیش‌نمایش، `node tests/hackathon/staff/serve.mjs` را اجرا کنید و نشانی چاپ‌شده را باز کنید. برای پیام کلی یا شنیده، در نشانی `preview.html` پارامتر `?choice=repeat` یا `?choice=hearsay` را بگذارید.

| مسیر آزمون | نتیجه |
| --- | --- |
| تأیید مشاهدهٔ رمپ صادقیه، سپس ممیزی درست | یک پیوست، بدون تغییر وضعیت رفع میدانی؛ پس از ممیزی اپراتور +۸ XP، مدیر +۱۲ XP. ثبت تکراری رد شد. |
| کشف تأیید اشتباهِ گزارش شنیده‌شده | علامت بازبینی، اپراتور +۰ XP، مدیر +۱۲ XP. با ممیزی درست قبلی، مدیر به ۲۴ XP و نشان «امین محله» رسید. |
| برگشت موجه پیام کلی یا شنیده | بدون پیوست یا XP فوری؛ بعد از ممیزی درست اپراتور +۸ XP و مدیر +۱۲ XP. |
| تصمیم بی‌دلیل یا ممیزی با دلیل مغایر | فرم بدون دلیل ثبت نشد؛ ممیزی با دلیل نامنطبق هیچ XP نداد. اعتبار خرج‌شدنی کارکنان صفر ماند. |

چهار تست خودکار API بدل گذشت. در مرورگر، تأیید و دو ممیزی در نمای ۳۹۰ پیکسل با کیبورد انجام شدند؛ صفحه اسکرول افقی نداشت و فوکوس پس از ثبت به پیام نتیجه رفت. مسیر برگشت موجه هم در مرورگر بررسی شد. اتصال و آزمون با هستهٔ اصلی به ادغام سهم وهاب وابسته است.

**روایت ۴۵ ثانیه‌ای برای داور**

«فلکهٔ دوم صادقیه آب گرفته؛ اما این پیام کلی به اکیپ نمی‌گوید کجا را بررسی کند. اپراتور آن را برای اصلاح برمی‌گرداند. حالا مشاهدهٔ مستقیم می‌رسد: ساعت ۱۴:۴۰ رمپ شمال‌غربی زیر آب است و ویلچر رد نمی‌شود. اپراتور با همین دلیل تأیید می‌کند. شاهد به پرونده اضافه شده و وضعیت رفع میدانی هنوز باز است. مدیر دلیل را با کلید نمونه می‌سنجد: اپراتور ۸ XP و مدیر ۱۲ XP می‌گیرند. در تمرین بعد، اپراتور یک شنیده را تأیید کرده؛ مدیر آن را برای بازبینی علامت می‌زند و فقط خودش ۱۲ XP می‌گیرد. ارزش دمو همین است: یک سرنخ قابل بررسی برای اکیپ و یک تصمیم قابل توضیح برای مدیر.»
