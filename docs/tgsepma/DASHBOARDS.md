# داشبورد نمونه‌کار رصد

مسیر معرفی: `/fa/dashboards` و `/en/dashboards`. نسخه کامل: `/dashboard-demo/index.html`.

این نمونه یک HTML مستقل با CSS، کد نمودار SVG و داده فشرده gzip درون همان فایل است. داده در مرورگر باز می‌شود و هیچ درخواست API، اتصال SQL، پردازش Python یا سرویس Docker جدید لازم ندارد. فایل در `public` قرار دارد و در همان انتشار فعلی Next.js ارائه می‌شود. مسیر و فایل Docker و تنظیمات دسترسی زیرساخت تغییر نمی‌کنند.

منبع خروجی فقط سناریوی ساختگی با شناسه `DEMO27-` پروژه رصد است؛ پیش از ساخت، تمام شناسه‌های ورودی کنترل شده‌اند. هیچ رشته اتصال، داده شخصی، رکورد خام پایگاه داده یا کلید ورود در این فایل قرار ندارد. انتساب موجودی بانک به شعبه و طرح یک فرض نمایشی است و نباید در اتصال واقعی تکرار شود.

۹ صفحه، ۳ استان/شعبه و ۴ طرح به همراه گزینه کل، سه نوع گروه‌بندی پایداری، جست‌وجو و مرتب‌سازی جدول، خروجی CSV، چاپ، پوسته و محاسبه سناریو در مرورگر موجود است. بازه عمومی ثابت، آبان ۱۴۰۴ تا مهر ۱۴۰۵ است. ۲۲۰ نتیجه از پیش محاسبه شده‌اند. بودجه حداکثر ۴۰ ردیف تفصیلی نشان می‌دهد؛ شاخص‌ها از کل بازه هستند. فرهنگ ساختار داخلی SQL و شواهد رکوردی در نمونه عمومی ارائه نمی‌شوند.

داده آموزشی از عملکرد واقعی یا تأیید سازمان تأمین اجتماعی حکایت ندارد. نام پروژه صرفاً حوزه نمونه تحلیل را بیان می‌کند. صفحه اصلی، دیدبان، نظرسنجی‌ها، ورود مدیریت و داده‌های موجود سایت تغییر داده نشده‌اند.

مرورگر باید از `DecompressionStream('gzip')` پشتیبانی کند؛ نسخه‌های جدید Chrome، Edge، Firefox و Safari این قابلیت را دارند. نسخه محلی کامل رصد همچنان از SQL می‌خواند؛ نمونه عمومی برای نمایش قابلیت‌هاست.
