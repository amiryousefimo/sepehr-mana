# سامانه هوشمند پایش و تحلیل مسائل شهری شهرآگاه (ShahrAgah)

> **ماک تعاملی و آماده ارائه در هکاتون**  
> پلتفرم هوشمند دریافت، تحلیل زبان طبیعی، تجمیع مکانی گزارش‌های شهروندی و پیشنهاد اولویت‌بندی ارجاع به معاونت‌های تخصصی مدیریت شهری.

---

## ۱. درباره پروژه

شهرآگاه یک راهکار مدرن سازمانی است که برای حل معضل پردازش حجم انبوه گزارش‌های پراکنده و تکراری شهروندان (مانند سامانه ۱۳۷) طراحی شده است. این سامانه با تحلیل معنایی متن گزارش‌ها و تجمیع آن‌ها بر اساس نزدیکی مکانی، مسائل واقعی شهر را شناسایی کرده و با محاسبه شاخص چندمعیاره اولویت (شدت، فراوانی، تاخیر زمانی و اهمیت معبر)، رسیدگی به آن‌ها را هوشمند و بهینه می‌کند.

---

## ۲. سناریوی اصلی دمو هکاتون (رویداد بارندگی شدید و آبگرفتگی صادقیه)

اپلیکیشن برای یک ارائه زنده و بی‌نقص هکاتونی آماده شده است. ترتیب اجرای سناریو به شرح زیر است:

1. **مرکز پایش شهر (داشبورد اولیه):**
   - مشاهده آمار پایه: ۲۴۸ گزارش دریافتی، ۷۶ مسئله شناسایی‌شده، ۸ مورد بحرانی و ۱۹ مورد در انتظار رسیدگی.
   - نمایش نقشه تعاملی تهران و پراکندگی مسائل بر اساس اولویت و رنگ.

2. **اجرای سناریوی بارندگی:**
   - با کلیک روی دکمه برجسته **«اجرای سناریوی بارندگی صادقیه»** در بنر یا هدر، سناریو به صورت مرحله‌ای فعال می‌شود.
   - **مرحله ۱:** ورود ۳۲ گزارش جدید همزمان با شروع بارش و نمایش اعلان Toast.
   - **مرحله ۲:** نمایش پردازش و تحلیل معنایی متن گزارش‌ها توسط موتور هوشمند.
   - **مرحله ۳:** خوشه‌بندی گزارش‌ها و تشکیل خوشه بحرانی آبگرفتگی روی نقشه.
   - **مرحله ۴:** فوکوس و زوم خودکار نقشه روی **فلکه دوم صادقیه** و نمایش نشانگر تپنده بحرانی.
   - **مرحله ۵:** نمایش پنل جمع‌بندی: شناسایی مسئله با اولویت ۸۹ از ۱۰۰ و ۳۲ گزارش متصل.

3. **مشاهده جزئیات و پرونده تحلیلی:**
   - با کلیک روی نشانگر نقشه یا سطر اول جدول، کشوی اطلاعاتی جامع باز می‌شود.
   - شامل ۵ نمونه گزارش واقعی به زبان محاوره‌ای فارسی شهروندان.
   - خلاصه هوش مصنوعی، تفکیک عوامل امتیازدهی (شدت، فراوانی، زمان، اهمیت).

4. **تأیید و ارجاع به واحد تخصصی:**
   - فشردن دکمه «تأیید و ثبت ارجاع به واحد تخصصی».
   - باز شدن مدال تأیید واحد «خدمات شهری / بررسی آبگرفتگی و مدیریت آب‌های سطحی».
   - تأیید ارجاع: تغییر وضعیت به «ارجاع‌شده»، ثبت در خط زمانی (Timeline) و صدور اعلان موفقیت.

5. **تغییر به «نمای عمومی شهروندان»:**
   - با کلید تغییر محیط در بالای صفحه، ارائه‌دهنده وارد پرتال شهروندی می‌شود.
   - نمایش همان مسئله بر روی نقشه عمومی با حفظ محرمانگی و بدون انتشار داده‌های هویتی شهروندان.

## ۳. هویت بصری و ویژگی‌های فنی

- **فریم‌ورک:** React + TypeScript + Vite
- **پالت رنگی اصلی (محیط نهادی و مدنی - تم روشن):**
  - **پس‌زمینه اصلی (Warm Ivory):** `#F1EEE5`
  - **سطوح و کارت‌ها (Surface White):** `#FAF9F5`
  - **رنگ اصلی سازمانی (Forest Green):** `#203B35`
  - **رنگ تأکیدی بحرانی (Terracotta):** `#D97852`
  - **رنگ هشدار (Warm Amber):** `#D5AA59`
  - **رنگ سبز ملایم سازمانی (Muted Green):** `#789184`
  - **رنگ متن و خطوط:** `#252D29` و `#DEDCD3`
- **سیستم تایپوگرافی رسمی:** فونت فارسی **Sahel (ساحل)** اثر صابر راستی‌کردار به صورت کاملاً محلی (Local WOFF2)، شامل وزن‌های استاندارد ۴۰۰ (Regular)، ۶۰۰ (SemiBold)، ۷۰۰ (Bold) و نسخه متغیر (Variable Font) با بهینه‌سازی کامل خطوط و کشیدگی‌های فارسی و پشتیبانی کامل از RTL.
- **نقشه تعاملی:** Leaflet و React Leaflet با OpenStreetMap و حالت وکتور آفلاین زیبا با خطوط ترافیکی شبکه تهران.
- **نمودارها:** Recharts شامل تحلیل سری زمانی گزارش‌ها، توزیع موضوعی، دونات سطوح اولویت و مقایسه مناطق.

## ۴. نحوه اجرا روی سیستم شخصی

### پیش‌نیازها
- Node.js نسخه 18 یا بالاتر
- npm

### دستورات اجرا

```bash
# نصب وابستگی‌ها (در صورت نیاز)
npm install

# اجرای سرور توسعه محلی
npm run dev
```

سپس آدرس محلی (معمولاً `http://localhost:5173`) را در مرورگر باز کنید.

### بررسی صحت بیلد نهایی
```bash
npm run build
```

## ۵. بخش‌های برنامه

1. **مرکز پایش شهر (داشبورد سازمانی):** پایش نقشه، شاخص‌های KPI، فیلترهای چندگانه و کنترل سناریوی بارندگی.
2. **پیگیری و مدیریت مسائل:** کارتابل جستجوپذیر و قابل فیلتر تمام پرونده‌ها با مرتب‌سازی بر اساس اولویت و تعداد گزارش.
3. **تحلیل و گزارش‌ها:** نمودارهای تحلیلی بینش‌افزا جهت تصمیم‌گیری مدیران ارشد شهرداری.
4. **نمای عمومی شهروندان:** محیط شفاف، مدرن و پالایش‌شده جهت اطلاع شهروندان از وضعیت محله‌ها.
5. **راهنمای دمو (ویژه هکاتون):** چیت‌شیت گام‌به‌گام برای ارائه‌دهنده در بالای صفحه.
